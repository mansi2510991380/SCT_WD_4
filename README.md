# 📌 Project Description

This project is an interactive **To-Do List Web Application** developed as part of the **SkillCraft Technology Web Development Internship**. It is built using **HTML, CSS, and JavaScript** and helps users organize and manage daily tasks through a simple, responsive, and user-friendly interface.

## 🚀 Features

- Add new tasks
- Mark tasks as completed
- Delete tasks
- Responsive design
- User-friendly interface
- Dynamic task management using JavaScript

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
